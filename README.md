# ELYSIA - Hotel Management System

A comprehensive hotel management and hospitality platform consisting of three core modules:

- **`backend/`**: Express / Node.js API server, authentication, room management, booking system, analytics, and security middleware.
- **`erp/`**: Hotel ERP & Staff Management Portal (Admin, Manager, Receptionist, Housekeeping, Operations).
- **`frontend/`**: Guest-facing Luxury Hotel Booking Website & Customer Experience Portal.

## Repository Structure

```text
ELYSIA/
├── backend/       # REST API server & database services
├── erp/           # Hotel Enterprise Resource Planning (ERP) application
├── frontend/      # Guest booking & hotel showcase website
└── .gitignore     # Git ignore configuration
```

## Getting Started

### 1. Backend Setup
```bash
cd backend
npm install
npm run dev
```

### 2. ERP System Setup
```bash
cd erp
npm install
npm run dev
```

### 3. Customer Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
